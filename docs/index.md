# PlayVisual User Manual

Welcome to the PlayVisual documentation. Use the navigation above to find what you need.

## What is PlayVisual?

PlayVisual is a **digital signage platform** that lets you design, schedule and display content across a network of screens. Admins build playlists of widget-based templates; player devices pull those playlists and render them in real time.
