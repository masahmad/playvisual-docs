# Uploading Media

---

## Where to go

**Media Studio → Upload Media**

---

## Selecting a client

If you have access to multiple clients, select the target client from the dropdown at the top of the page before uploading. Media is scoped to that client.

---

## Uploading files

1. Drag and drop files onto the upload zone, or click the zone to open a file picker
2. Multiple files can be selected in one batch
3. Progress is shown per file as each upload completes
4. Uploaded files appear immediately in the Media Library

### Supported formats

| Type | Formats |
|------|---------|
| Images | JPEG, PNG, GIF, WebP, SVG |
| Videos | MP4, WebM, MOV |
| Audio | MP3, WAV, OGG |

---

## After uploading

Files are stored in Google Cloud Storage. Once uploaded, you can:

- Add **tags**, **mood**, **category** and other metadata by clicking the file in the Media Library
- Run **Auto-tag** to get AI-suggested tags based on image content
- Use the file in a widget by selecting it in the widget's media picker

---

## Storage limit

There is no hard limit enforced in the interface, but very large files (>500 MB) may time out on slow connections. Contact your Superadmin if you need to upload large batches.
