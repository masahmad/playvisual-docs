# Admin Guide

This guide covers the day-to-day tasks an Admin performs on the PlayVisual platform.

---

## What Admins do

Admins manage a single client (organisation) within PlayVisual. Typical tasks include:

| Task | Where |
|------|-------|
| Add and manage users | Users menu |
| Register and approve display devices | Devices menu |
| Create playlists and templates | Playlists menu |
| Configure widget content | Playlist editor |
| Upload and organise media | Media Studio |
| Generate AI images/videos | Media Studio → AI Studio |
| Connect Google Sheets data sources | Playlists / GSheet widget |
| Configure app settings | Settings |

---

## Admin vs Superadmin

Admins are scoped to a single client. They cannot:

- Create or delete clients
- See or modify other clients' data
- Allocate AI credits
- Access the SA Dashboard

For cross-client operations, ask a Superadmin.
