# Managing Users

Admins can invite and manage users within their client organisation.

---

## Viewing users

Go to **Users** in the top navbar. The list shows all users belonging to your client.

Superadmins see users across all clients and can filter by client.

---

## Inviting a new user

1. Click **+ Add User**
2. Enter the user's:
   - **Email address**
   - **Name**
   - **Password** (temporary — advise the user to change it)
   - **Role** — see [Roles & Permissions](../getting-started/roles.md)
3. Click **Save**

The user can now log in with those credentials.

---

## Roles

| Role | Description |
|------|-------------|
| **Admin** | Full access to that client's data, users, devices and playlists |
| **Moderator** | Can edit existing playlists but cannot manage users or devices |

See [Roles & Permissions](../getting-started/roles.md) for the full breakdown.

---

## Editing a user

Click the edit icon on a user row to change their name, password or role.

---

## Deleting a user

Click the delete icon. The user is immediately unable to log in.

---

## Preview accounts

Users marked as **preview** are used for testing and are hidden from the main user list by default. Toggle **Hide preview users** in the Users header to show or hide them.

---

## Superadmin notes

Superadmins can also see and manage all users across all clients, and can reassign a user to a different client.
