# Moderator Guide

Moderators can edit existing playlist content without having full admin access to users, devices or client settings.

---

## What moderators can do

| Task | Available? |
|------|-----------|
| View and edit existing playlists | Yes |
| Configure widget content | Yes |
| View the Media Library | Yes |
| Upload new media | Limited (depends on client config) |
| Add or delete playlists | No |
| Manage users | No |
| Manage devices | No |
| Access AI Studio | Depends on client config |
| Access Settings | No |

---

## Navigation

Moderators see a reduced navigation bar:

- **Playlists** — the primary working area
- **Media Studio** — view and select media for widgets
- **Language selector** and **LogOut**

---

## Typical workflow

1. Log in — you land directly on the Playlists page
2. Select the playlist you need to update
3. Choose a template (slide)
4. Click the widget you want to edit
5. Make changes in Form View
6. Changes save automatically and reach all connected devices in real time

---

## Limitations

Moderators cannot:

- Create or delete playlists (only admins can)
- Add or remove templates from a playlist
- Add or remove widgets from a template
- Approve new devices

If you need to do any of these, contact your Admin.
