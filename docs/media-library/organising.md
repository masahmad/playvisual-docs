# Organising & Tagging

Tagging and categorising your media makes it easier to find assets when building playlists, and enables filtering in the Media Library and Media Selector modal.

---

## Opening the metadata panel

Click any media card in the library to open the detail panel on the right side.

---

## Metadata fields

| Field | Description |
|-------|-------------|
| **Tags** | Free-form keywords — add multiple, press Enter to confirm each |
| **Mood** | Emotional tone (e.g. Energetic, Calm, Professional) |
| **Category** | Content category (e.g. Product, Brand, Event) |
| **Suitable for** | Target context (e.g. Retail, Corporate, Hospitality) |
| **Usage type** | How the asset is used (e.g. Background, Feature, Thumbnail) |
| **Orientation** | Landscape, Portrait or Square |
| **Text contrast** | Light or Dark — helps place readable overlaid text |

Click **Save metadata** after making changes.

---

## Auto-tagging with AI

Click **Auto-tag** on the detail panel. PlayVisual sends the image to an AI vision model, which suggests relevant tags. Review and confirm the suggestions before saving.

!!! note
    Auto-tag is available for images only. Video thumbnails are not currently analysed.

---

## Filtering the library

Use the filter bar above the media grid to narrow results:

- **Media type** — Image, Video, Audio
- **Tag** — type a keyword to filter by tag
- **Mood / Category** — dropdown filters
- **Global media** — toggle to include or exclude Global Library assets

Filters combine — for example, filter by "Image" + tag "logo" to show only tagged logo images.

---

## Searching

The search box in the filter bar matches on filenames and tags. Partial matches are supported.
