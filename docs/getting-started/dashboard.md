# Dashboard Overview

After logging in you land on the **Home** page. It provides a quick summary of activity and shortcuts to common tasks.

---

## Navigation bar

The top navbar is always visible. It contains:

| Element | Description |
|---------|-------------|
| PlayVisual logo | Returns to Home |
| **Users** icon | Jump to User Administration |
| **Devices** icon | Jump to Device Administration |
| **Pending** icon | Devices awaiting approval |
| **Playlists** icon | Jump to Playlist Administration |
| **Media Studio** icon | Jump to Media Studio (library + AI) |
| Language selector | Switch the interface language |
| Settings gear | App settings |
| Home icon | Return to Home dashboard |
| Role badge | Shows your role (Superadmin / Admin / Mod) |
| **LogOut** | End your session |

Superadmins also see a **Clients** icon. Moderators see a reduced set.

---

## Home dashboard panels

The dashboard is role-dependent.

### Superadmin home

- Quick-link cards to all admin areas
- Link to the **SA Dashboard** (AI provider health, credit allocations, storage usage)

### Admin home

- Quick-link cards to Devices, Users, Playlists, Media Studio
- Any pending notifications (e.g. Google Sheets setup requests)

---

## Theme & appearance

You can change the colour theme of the admin interface under **Settings → Appearance**. Available themes include Light, Sky Blue, Grey, Dark Grey, Dark, Midnight, Ocean and Sunset. Your choice is saved in the browser and persists across sessions.
