# Global Library

The **Global Library** is a shared pool of media assets available to all clients, managed by Superadmins.

---

## What is it for?

Use the Global Library to:

- Share brand assets (logos, approved imagery) across all clients without duplicating storage
- Maintain a central library of stock media that all clients can use in their playlists

---

## Accessing global media

Toggle **Show global media** in the Media Library filter bar. Global assets appear in the grid alongside your client's own media.

Global assets are **read-only** for non-SA users — they cannot be edited, moved or deleted.

---

## Copying an asset to the Global Library

Only Superadmins can add assets to the Global Library.

1. Open a media asset's detail panel
2. In the **Copy / Move** section, select `_global` as the destination
3. Click **Copy**

The asset is copied to the Global Library. The original in the client's library is unchanged.

---

## Removing from the Global Library

Only Superadmins can remove global assets.

Navigate to the Global Library (select `_global` as the active client), open the asset and click **Delete**.

If a copy reference (`globalCopyId`) was set on the source document, it is automatically cleared when the global copy is deleted.

---

## Storage

Global Library storage is tracked separately from per-client storage. The **SA Dashboard** shows a breakdown including global totals.
